# AGENTS.md

## Project purpose


The purpose of this project is to produce a response to the comments of the two reviewers after submission of the paper "[Floquet Topological Frequency-Converting Amplifier](https://arxiv.org/abs/2512.08880)"


## Repository organization

This is the structure of this repository

project/
├── AGENTS.md
├── docs
├── paper
├── referee reports

"docs" is a folder that contains information on existing literature, suggestions for a possible response to the comments by the referees.

"paper" contains the .tex an related files necessary to write the manuscript

"referee reports" contains the referee reports
